# Read this before doing anything with git in this checkout

*Left 2026-08-11 by the probefix session. Two things went wrong that are easy to fix and confusing
to discover later.*

## 1. A parallel session's commit landed on the wrong branch, and it was my fault

Two agent sessions shared this ONE working tree. I ran `git checkout -b probe-decoder-brit` for the
`probefix/` work without accounting for that, so the other session's next `git commit` —
**6461f23 "computation-correctness: the two steps are not a mixture, and where the jump comes
from"**, 12 files of `cc_ladder*` / `cc_strata*` / `brit_guard_dose*` — landed on **my** branch
instead of `master`.

Nothing is lost. `master` is still at `afdb146` where it was. But that commit is sitting under a
branch named for someone else's experiment, which is not where its author will look for it.

To put it back where it belongs:

```bash
git checkout master
git cherry-pick 6461f23        # their work, now on master where they expected it
```

`probe-decoder-brit` can then keep it too (it is already in that history) or be rebased to drop it.

**The general lesson, since this box runs several sessions against one tree:** branching is not a
session-local action here. Anyone creating a branch moves the shared HEAD for everybody.

## 2. Nothing is pushed, and this box does not persist

`vast-capabilities | jq '.instance.workspace_is_volume'` → **`false`**. The container filesystem,
including `.git`, is wiped on recycle. There are no git credentials on the box (no
`~/.git-credentials`, no helper configured, no `GH_TOKEN`, no `gh`), so I could not push. A local
commit here protects nothing — `STATE.md` records two sessions already lost this way.

Two ways out:

```bash
# A — push, from a shell with your own auth
cd /workspace/reward-depth && git push -u origin probe-decoder-brit && git push origin master

# B — no credentials needed: download this file and clone from it locally
#     /workspace/reward-depth-probefix.bundle   (verified: "records a complete history")
git clone reward-depth-probefix.bundle reward-depth
```

The bundle contains **both** branches and therefore both sessions' commits, so option B rescues the
parallel session's work as well as mine.

## 3. Cross-session dependency worth knowing about

`probefix/` reads `supervisor/britishness/dosed/brit_dose20.jsonl`, generated by
`supervisor/brit_dose_data.py`. Both belong to the parallel session and were still untracked when I
last looked. Until they are committed, the `probefix` branch is not reproducible from a fresh
checkout.
