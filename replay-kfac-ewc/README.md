# replay-kfac-ewc

This package replaces a live reference model during alignment training with a
fixed, replay-estimated local prior. It has two parts:

1. Generate text from a frozen causal LM and store the sampled token sequences.
2. Estimate per-linear-layer K-FAC factors on those own-model samples and use
   them as a differentiable EWC penalty during LoRA or full-rank training.

The package is the reusable extraction of the replay/K-FAC implementation in
the alignment project. It does not contain project-specific datasets, model
wrappers, scratch paths, or training objectives.

## Install

From the source directory:

```bash
python -m pip install -e '.[huggingface,test]'
pytest
```

Or install the supplied wheel, adding the Hugging Face dependencies:

```bash
python -m pip install replay_kfac_ewc-0.1.0-py3-none-any.whl
python -m pip install 'transformers>=4.44' 'peft>=0.12'
```

Python 3.10+ and PyTorch 2.1+ are supported. Pin the model revision when
producing a real artifact; replay generated by one checkpoint is not a Fisher
sample for a different checkpoint.

## End-to-end workflow

### 1. Generate replay shards

The default prefix distribution matches the research runs: 25% begin with
BOS, while 75% begin with a uniformly sampled 1–8 token non-special prefix.
Each sequence has its own RNG seed, so a resume or changed shard layout does
not change completed records.

```bash
replay-kfac-ewc generate \
  --model Qwen/Qwen2.5-3B \
  --revision YOUR_PINNED_REVISION \
  --output artifacts/replay/shard-000.jsonl \
  --num-sequences 1000 \
  --seq-start 0 \
  --min-new-tokens 64 \
  --max-new-tokens 384 \
  --device cuda:0
```

Produce additional shards with disjoint `--seq-start` ranges. Generation is
resumable by default. Every shard gets a sidecar manifest with its effective
configuration, content hash, and token counts.

For task-conditioned replay, provide text lines or JSONL records containing
`prompt`, `prompt_ids`, or `token_ids`:

```bash
replay-kfac-ewc generate \
  --model /models/frozen-checkpoint \
  --output artifacts/replay/task.jsonl \
  --num-sequences 500 \
  --seeding-mode prompt \
  --prompts prompts.jsonl
```

### 2. Merge and freeze the split

```bash
replay-kfac-ewc merge \
  --inputs artifacts/replay/shard-*.jsonl \
  --output artifacts/replay/library.jsonl \
  --heldout-fraction 0.1
```

The merge rejects conflicting sequence IDs, removes exact duplicate token
sequences, sorts by sequence ID, and assigns train/held-out membership with a
stable hash. The held-out part is for measuring actual replay KL; it is not
used for factor estimation.

### 3. Estimate K-FAC factors

Selectors match full module names or suffixes. Repeating a suffix selects that
projection in every layer.

```bash
replay-kfac-ewc estimate \
  --model /models/frozen-checkpoint \
  --corpus artifacts/replay/library.jsonl \
  --output artifacts/kfac \
  --target q_proj \
  --target k_proj \
  --target v_proj \
  --target o_proj \
  --batch-size 1 \
  --device cuda:0 \
  --placement auto \
  --checkpoint artifacts/kfac-accumulator.pt \
  --checkpoint-every 100
```

The command prints the exact dense-accumulator memory requirement before it
allocates anything. The default 64 GiB guard refuses an oversized target set.
Use fewer projections, a smaller model, a machine with enough RAM/VRAM, or
explicitly change the guard. This estimator does not silently replace a dense
factor with a diagonal one.

Resume a preempted pass by repeating the same command with `--resume`. The
rolling checkpoint contains the dense sums and the next record index; loading
it verifies the ordered replay digest and every target-module shape before any
work continues. Because the checkpoint is a dense snapshot, budget temporary
disk for roughly twice the reported accumulator size during atomic replacement.

Accumulation is exact and dense in fp32. Compression happens once, after the
global token normalization: each factor stores the leading eigenspace needed
for 99% trace energy, capped at rank 1024, plus the exact diagonal of the
discarded residual.

Inspect and verify a saved bundle with:

```bash
replay-kfac-ewc inspect --factors artifacts/kfac
```

### 4. Add the penalty to LoRA training

```python
from replay_kfac_ewc import FactorBundle, KFACEWC

factors = FactorBundle.load("artifacts/kfac", device="cuda:0")
anchor = KFACEWC(factors, coefficient=0.05)

task_loss = preference_loss(model, batch)
ewc_loss = anchor.penalty_from_peft(model, adapter_name="default")
loss = task_loss + ewc_loss
loss.backward()
optimizer.step()
```

`penalty_from_peft` reads PEFT's live LoRA A/B tensors and computes

```text
0.5 * s^2 * tr[(B^T G B)(A_lora A A_lora^T)]
```

using only rank-by-rank inner matrices. It does not form the full LoRA weight
delta. The returned scalar remains in the autograd graph and sends gradients
to both LoRA factors.

For a custom adapter, pass a mapping of full factor names to `LoRADelta`. For
full-rank training, call `capture_reference` once and then
`penalty_against_reference` during training. See
[`examples/training_fragment.py`](examples/training_fragment.py).

## Calibrating the coefficient

The factor penalty is a fixed-reference local quadratic, not a globally exact
drift meter. Use small perturbations and the held-out replay split to compare:

- predicted `KFACEWC` penalty;
- measured `mean_forward_kl(reference_model, candidate_model, heldout_records)`.

`fit_calibration(predicted, measured)` reports the local log-log slope, rank
correlation, and the geometric-mean `measured KL / predicted penalty` ratio.
A slope near one is evidence that the perturbations are still in the local
quadratic regime. Calibration fixes an overall scale; it cannot repair a
directionally wrong factor model.

In ordinary training, retain held-out replay KL as the behavioral check and
use the K-FAC term as the efficient training prior. If updates leave the local
regime, refresh the reference and factors rather than treating a larger
coefficient as a cure.

## What is and is not estimated

- When the corpus was sampled from the same frozen model, its next tokens are
  own-model labels, giving the true-Fisher sampling convention rather than an
  empirical Fisher on external labels.
- Activation factors are `A = E[a a^T]`; output-gradient factors are
  `G = E[g g^T]`.
- The loss is summed over generated-token positions in each batch and divided
  once by the global position count.
- One combined backward is used per batch. In a transformer, the captured
  gradient at a token therefore contains causal contributions from later
  scored losses. This is the standard tractable K-FAC convention, not an
  isolated backward pass for every token.
- Factors are fixed. This is EWC around a chosen reference, not online K-FAC,
  natural-gradient optimization, or a claim that the approximation remains
  exact far from the reference.
- Replay records store token IDs and diagnostics. Factor estimation performs
  teacher forcing through the frozen model; it does not train directly on
  embeddings.

More detail is in [`DESIGN.md`](DESIGN.md).

## Artifact contract

Replay JSONL uses schema version 1 and includes the prefix, full token sequence,
sampling seed, generated-token mean log-probability, repeat-loop flag, and
split. Factor directories contain:

```text
factors.pt       tensors and estimator metadata
manifest.json    dimensions, retained ranks/energy, and SHA-256
```

Treat the replay library, model revision, factor directory, and training
configuration as one immutable experiment unit.
